# Contributing

MailFlow Lab values small, testable changes and inspectable evidence.

1. Start behavior changes from a feature specification.
2. Use only synthetic data and `.test` email domains.
3. Keep the default path dry-run-only and offline.
4. Add a failing test before changing behavior when practical.
5. Run `npm run check` and report the result.
6. Declare AI assistance and confirm that a human reviewed the final diff.

By contributing, you agree that your contribution is licensed under Apache-2.0.
